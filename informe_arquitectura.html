01 — Resumen Ejecutivo
01 — Executive Summary

De una aplicación a un ecosistema digital

From one application to a digital ecosystem

La plataforma digital del FRA RSS 2025 se está rediseñando para separar dos propósitos hasta ahora compartidos en una única aplicación Streamlit: la visualización pública de resultados y las herramientas internas de análisis y edición. Esta separación responde a necesidades concretas de usabilidad, escalabilidad y control de acceso.

The FRA RSS 2025 digital platform is being redesigned to separate two purposes currently shared in a single Streamlit application: the public visualization of results and the internal analysis and editing tools. This separation responds to concrete needs for usability, scalability, and access control.

La propuesta consiste en tres componentes interconectados: (1) una Landing Page pública que actúa como punto de entrada y enrutamiento, (2) una Plataforma de Resultados basada en Vercel/Next.js para acceso público y de delegaciones, y (3) la Plataforma de Análisis Streamlit existente, refactorizada y mejorada para el personal FAO y analistas autorizados. Los tres componentes comparten una única base de datos PostgreSQL centralizada en Supabase y un sistema de autenticación unificado.

The proposal consists of three interconnected components: (1) a public Landing Page acting as entry point and routing hub, (2) a Results Platform based on Vercel/Next.js for public and delegation access, and (3) the existing Streamlit Analysis Platform, refactored and improved for FAO staff and authorized analysts. All three components share a single PostgreSQL database centralized in Supabase and a unified authentication system.

✅
Principio clave: ningún dato se duplica. Ambas plataformas leen y escriben sobre la misma base de datos, con diferentes niveles de acceso controlados por roles JWT. Key principle: no data is duplicated. Both platforms read and write to the same database, with different access levels controlled by JWT roles.

07 — Autenticación y Autorización
07 — Authentication and Authorization

Un sistema de identidad, dos plataformas

One identity system, two platforms

Ambas plataformas usan Supabase Auth como única fuente de verdad para identidades. Los usuarios tienen una única cuenta con email/contraseña, y su rol (admin, analyst, viewer) se incluye automáticamente en el JWT mediante un hook de base de datos PostgreSQL.

Both platforms use Supabase Auth as the single source of truth for identities. Users have a single account with email/password, and their role (admin, analyst, viewer) is automatically included in the JWT via a PostgreSQL database hook.

Proceso por idioma adicional

Process per additional language

  • Traducción automática (FR/RU/ZH): ~200-350 strings de UI por plataforma. Se generan con IA (DeepL o Claude), se revisan una sola vez para validar terminología forestal, y se integran al sistema i18n existente (mismo mecanismo ES↔EN). Sin bloqueos técnicos.
  • Árabe (AR) — único bloqueo técnico real: requiere soporte RTL (dirección de texto derecha-izquierda). Implica cambios de CSS adicionales (dir="rtl", inversión de layouts flexibles, alineación de iconos). La traducción en sí es automática; el trabajo es el layout. Evaluable si el proyecto lo requiere.
  • Recomendación: implementar FR como primer idioma adicional, dado el peso de la francofonía en África subsahariana — la región con mayor cobertura forestal del FRA.
  • Automated translation (FR/RU/ZH): ~200-350 UI strings per platform. Generated with AI (DeepL or Claude), reviewed once to validate forest terminology, and integrated into the existing i18n system (same ES↔EN mechanism). No technical blockers.
  • Arabic (AR) — the only real technical blocker: requires RTL (right-to-left) text direction support. Involves additional CSS changes (dir="rtl", flex layout inversion, icon alignment). The translation itself is automated; the work is the layout. Worth evaluating if the project scope requires it.
  • Recommendation: implement FR as the first additional language, given the weight of francophone Africa — the region with the highest forest coverage in FRA.
